# Dhwani Dance School - High-Converting Bharatanatyam Platform

This is a premium, female-exclusive online Bharatanatyam platform prototype optimized for Western markets. It demonstrates a complete end-to-end customer onboarding and checkout flow, highlighting Stripe subscription orchestration and localized 1-on-1 scheduling.

## Key Features

1. **Elegant Design System**: Built with modern typography (Outfit and Playfair Display), deep maroon velvet base gradients (`#0a0405` to `#801a2b`), and warm champagne gold accents. Fully responsive for desktop, tablet, and mobile browsers.
2. **Interactive Brand Video Simulator**: Features a custom HTML Canvas particle-path generator illustrating classical geometry and mudra configurations. Tapping the sound toggle controls the ambient Carnatic instrumental audio track in compliance with modern browser sound guidelines.
3. **Frictionless Google OAuth Modal**: Initiates standard email & identity extraction to drop conversion dropout rates by up to 40%.
4. **Time Zone Smart-Scheduler**: Automatically retrieves the user's browser location (e.g. `EST`, `GMT`, `PST`) and populates 3 upcoming days with locally timed demo slots.
5. **Premium Stripe Node Checkout**: Presents:
   - $50 3-Class Entry Pass (One-time payment).
   - $1,599/year Certification Pass (with active Credit Card EMI installment calculations illustrating $133.25/month).
6. **Background Webhook Log Panel**: Instantly demonstrates background integrations upon authorized checkout:
   - Visual success UI update.
   - welcome kit dispatch notification preview.
   - WhatsApp meta API push text simulation.
7. **Personalized Member Dashboard**: Redirects users to their personalized dashboard after 5 seconds where they can see their upcoming demo schedule, direct classroom entry button, and download syllabus resources.

## Running Locally

To view the prototype locally, start a simple HTTP server in this directory. 

For example, using Python:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
Alternatively, open `index.html` directly in your browser.
